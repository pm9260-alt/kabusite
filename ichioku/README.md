# 1億分の1（仮）　第1段階の試作品

仕様書（第4版）にもとづく試作品です。人生の進め方・画面・データの取り込み・公開前の検査の仕組みはできています。2026年10月16日に統計の取り込みを始め、**47都道府県・1,890市区町村の出生数・進学率・求人倍率・産業の割合、全国の非正規の割合・所得・死因・普及率・名前の流行などは本物の数字に置き換えました**。まだ仮の値が14項目残っているため、公開はできません（公開前の検査で必ず止まるようにしてあります）。取り込みの中身は `docs/統計の取り込み.md` にまとめています。

## 追加した内容（作る人の指示 2026年10月16日）

- **性的少数者**：生まれたときに、国の委託調査の割合（男4.7%・女3.4%）で性的少数者かどうかを抽選する。該当すると、気づき・からかい・自ら命を絶つことを考える夜・職場での打ち明けなどの場面が出る。17歳で「打ち明けるかどうか」、26歳で同性のパートナーとの暮らし方を遊ぶ人が選ぶ。法律上の結婚はできず、住んでいる場所にパートナーシップ制度ができた年からは宣誓できる。つらい場面では相談先を必ず出す
- **その土地にしかないもの**：47都道府県の祭り・行事・食・条例・方言の場面（ねぶた、だんじり、上毛かるた、香川県のゲーム条例、沖縄の慰霊の日など）。住んでいる都道府県でだけ出る。今は試験用の3都道府県（秋田県・東京都・兵庫県）で動き、ほかの県は統計の取り込みで県を足すと自動で出る
- 新しく使う資料（厚生労働省の委託調査、ReBit の調査、全国パートナーシップ制度共同調査、各県・市町村の公表資料、商業統計）は `data-src/national.mjs` の出典の一覧に、了承日つきで登録した

## 1800〜2000年生まれへの広げ方（作る人の指示 2026年10月16日）

- 生まれる年は1800〜2000年のどの年も同じ確率。トップ画面は年を選ばず「生まれる」だけにした
- 江戸時代の身分は抽選する。被差別身分は解放令（1871年）の時点の人数（28万人あまり）から全国一律の割合にし、住む場所・仕事・つき合いの制限や、解放令のあとも続いた差別を事実に沿って書いた
- 蝦夷地（アイヌ）と琉球も入れる。アイヌは1804〜1873年の人口の記録で抽選し、1876年に和風の名前を名乗らされたこと、サケ漁の禁止、北海道旧土人保護法などを出す。琉球は士の割合（1800年28%、1852年38%）で抽選し、名前は童名、琉球処分・方言札・ソテツ地獄・沖縄戦・アメリカの統治・本土復帰を出す。本土の風習の場面（正月の雑煮・氏神さまの祭りなど）はアイヌと琉球の人には出さない
- 統計がない部分は研究の目安や推計で埋め、根拠の画面に「推計」の印を出す（一覧は `docs/統計の取り込み.md`）

## 動かし方（Windows）

1. e-Stat に利用登録し、マイページで「アプリケーションID」を発行する
2. PowerShell で `ichioku` フォルダーを開き、最初の1回だけ次を動かす
   ```
   powershell -ExecutionPolicy Bypass -File .\scripts\setup-keys.ps1
   ```
3. あとは毎回これだけで全工程が順に走る（Node.js がなければ自動で入れる）
   ```
   powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1
   ```
   18章の確認だけしたいときは `-Survey`、試験モードだけなら `-TestOnly` を後ろに付ける。

画面を手元で見るだけなら、`site` フォルダーをそのまま Cloudflare Pages に置くか、`npx http-server site` で開く。

## 今の検査の結果（本番の束・47都道府県、2026年10月16日）

1975〜2000年生まれ（26年分×300人）：場面の数（636）、場面の偏り、空の年0、同じ場面の重複0、矛盾0、実名、禁止語、使わない言葉、文字の混入、タグの開閉、コントラスト比、全市区町村で人生が最後まで動くか、統計との差（大学進学率 差1.3・平均寿命 差-0.2・婚姻率 差-3.0・非正規の割合 差0.3、すべて±3以内）がすべて合格

1800〜1974年生まれ（35年分×600人＝2万1000人）：人生が止まらずに最後まで動く（抽選で選ばれなかった旧国・都道府県も1人ずつ回した）、文の置き換え漏れなし、アイヌと琉球の人に本土の風習の場面が出ない、家族の年齢の矛盾なし、自分の出来事が空の年0.2%、統計との差（0歳で亡くなる割合 差0.0・小学校に通った割合 差0.7・高校進学率 差-1.8・50歳までに結婚した割合 差0.0、すべて±3以内）がすべて合格

不合格：
- 数字が仮の値のまま（残り14項目。一覧は `docs/統計の取り込み.md`）

目標に届いていないもの：1975年からの年表の1年あたり5種類（52年が5種類に満たない）

## 仕様書の解釈で決めたこと（作る人の了承済み 2026年10月15日・16日）

- 「時代の場面が15%以上」は、2026年までの年だけで数えた。2027年以降は6-5により時代の場面を出さないため、一生全体で数えると9%前後になり、どの生まれ年でも必ず不合格になるため
- 「平均寿命が元の統計から±3」は、生命表（年ごとの値と将来推計）から計算した「その生まれ年の人が平均して何歳まで生きるか」と比べた
- 「地元に残った人」は、30歳の時点で生まれた都道府県に住んでいる人として数えた
- 8章の一覧にない統計（患者調査・感染症発生動向調査・学校保健統計調査）を、健康と学校の場面の根拠として使う
- 「自動で回した人生で全市区町村が選ばれるか」は、統計どおりの割合で選ばれなかった市区町村だけ、生まれる町を指定して1人ずつ人生を最後まで回して確かめる（2026年10月16日）
