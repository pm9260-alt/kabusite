# 1億分の1（仮）　第1段階の試作品

仕様書（第4版）にもとづく試作品です。人生の進め方・画面・データの取り込み・公開前の検査の仕組みはできていますが、**数字はすべて仮の値**です。統計の取り込みが終わるまで公開はできません（公開前の検査で必ず止まるようにしてあります）。

## できていること

| 部分 | 中身 | 置き場所 |
|---|---|---|
| 人生の進め方 | 生まれる町・家庭・きょうだい・祖父母の抽選、毎年の「その年の世の中」と「自分の出来事」、分かれ道5か所（中学受験・高校・18歳の進路・就職・結婚）、家族の生死、景気と物価の影響、家に物が来る時期、災害の地域差、亡くなる年と死因、同じ町・同じ年の100人のその後 | `site/js/engine.js` |
| 画面 | トップ（生まれる年を1年刻みで選ぶ）、人生の画面（一時停止・倍速・次の年へ・家族・これまで）、出来事を押すと統計が出る画面、最期の画面、サイトの説明 | `site/` |
| データ | 時代の年表（1975〜2025年、113行）、場面311、普及率8品目、名前の流行、試験用の3都道府県（秋田県・東京都・兵庫県）各4市区町村 | `data-src/` → `site/data/` |
| 取り込み | e-Stat の API で表を探して取る仕組み。続きから再開、失敗は飛ばして最後に一覧 | `tools/fetch.mjs`、`tools/sources.json` |
| 検査 | 15章の公開前の検査、2章の表の検査、使わない言葉・簡体字の混入などの追加の検査 | `tools/check.mjs` |
| 一括実行 | 試験モード → 本番 → 検査 → 公開 | `scripts/run.ps1` |

## 動かし方（Windows）

1. e-Stat に利用登録し、マイページで「アプリケーションID」を発行する
2. PowerShell で `ichioku` フォルダーを開き、最初の1回だけ次を動かす
   ```
   powershell -ExecutionPolicy Bypass -File .\scripts\setup-keys.ps1
   ```
3. あとは毎回これだけで全工程が順に走る（Node.js がなければ自動で入れる）
   ```
   powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1
   ```
   18章の確認だけしたいときは `-Survey`、試験モードだけなら `-TestOnly` を後ろに付ける。

画面を手元で見るだけなら、`site` フォルダーをそのまま Cloudflare Pages に置くか、`npx http-server site` で開く。

## 今の検査の結果（試験モード）

合格：場面の偏り（学歴と仕事 10.7%、時代 20.9%）、空の年0、同じ場面の重複0、矛盾0、使える年の範囲、実名、禁止語、文字の混入、タグの開閉、コントラスト比、統計との差（大学進学率・平均寿命・婚姻率・非正規の割合がすべて±3以内）

不合格（データがそろえば外れるもの）：
- 数字が仮の値のまま
- 年表の2026年が空（統計がまだ出ていない）
- 年表113行の出典が未確認
- 場面が311で、目標の600に足りない
- 8章の一覧にない統計（患者調査・感染症発生動向調査・学校保健統計調査）を健康と学校の場面の根拠に使っている
- 相談先の名前と番号が未確認

## 仕様書の読み方で決めたこと（作る人の確認待ち）

- 「時代の場面が15%以上」は、2026年までの年だけで数えた。2027年以降は6-5により時代の場面を出さないため、一生全体で数えると9%前後になり、どの生まれ年でも必ず不合格になるため
- 「平均寿命が元の統計から±3」は、生命表（年ごとの値と将来推計）から計算した「その生まれ年の人が平均して何歳まで生きるか」と比べた
- 「地元に残った人」は、30歳の時点で生まれた都道府県に住んでいる人として数えた
