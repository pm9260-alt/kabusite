# 1000分の1

仕様書（第4版）にもとづく試作品です。人生の進め方・画面・データの取り込み・公開前の検査の仕組みはできています。2026年10月16日に統計の取り込みを始め、**47都道府県・1,890市区町村の出生数・進学率・求人倍率・産業の割合、全国の非正規の割合・所得・死因・普及率・名前の流行などは本物の数字に置き換えました**。2026年10月17日に残っていた仮の値14項目もすべて公表資料の数字に置き換えました（報告書や Excel からの取り出しは `tools/extra.py`）。取り込みの中身は `docs/統計の取り込み.md` にまとめています。

## 追加した内容（作る人の指示 2026年10月16日）

- **性的少数者**：生まれたときに、国の委託調査の割合（男4.7%・女3.4%）で性的少数者かどうかを抽選する。該当すると、気づき・からかい・自ら命を絶つことを考える夜・職場での打ち明けなどの場面が出る。17歳で「打ち明けるかどうか」、26歳で同性のパートナーとの暮らし方を遊ぶ人が選ぶ。法律上の結婚はできず、住んでいる場所にパートナーシップ制度ができた年からは宣誓できる。つらい場面では相談先を必ず出す
- **その土地にしかないもの**：47都道府県の祭り・行事・食・条例・方言の場面（ねぶた、だんじり、上毛かるた、香川県のゲーム条例、沖縄の慰霊の日など）。住んでいる都道府県でだけ出る。今は試験用の3都道府県（秋田県・東京都・兵庫県）で動き、ほかの県は統計の取り込みで県を足すと自動で出る
- 新しく使う資料（厚生労働省の委託調査、ReBit の調査、全国パートナーシップ制度共同調査、各県・市町村の公表資料、商業統計）は `data-src/national.mjs` の出典の一覧に、了承日つきで登録した

## 1800〜2000年生まれへの広げ方（作る人の指示 2026年10月16日）

- 生まれる年は1800〜2000年のどの年も同じ確率。トップ画面は年を選ばず「生まれる」だけにした
- 江戸時代の身分は抽選する。被差別身分は解放令（1871年）の時点の人数（28万人あまり）から全国一律の割合にし、住む場所・仕事・つき合いの制限や、解放令のあとも続いた差別を事実に沿って書いた
- 蝦夷地（アイヌ）と琉球も入れる。アイヌは1804〜1873年の人口の記録で抽選し、1876年に和風の名前を名乗らされたこと、サケ漁の禁止、北海道旧土人保護法などを出す。琉球は士の割合（1800年28%、1852年38%）で抽選し、名前は童名、琉球処分・方言札・ソテツ地獄・沖縄戦・アメリカの統治・本土復帰を出す。本土の風習の場面（正月の雑煮・氏神さまの祭りなど）はアイヌと琉球の人には出さない
- 統計がない部分は研究の目安や推計で埋め、根拠の画面に「推計」の印を出す（一覧は `docs/統計の取り込み.md`）

## 1000〜2000年生まれへの広げ方（作る人の指示 2026年10月16日）

- 生まれる年は1000〜2000年のどの年も同じ確率（作る人の判断）。およそ8割の人生が1800年より前になる
- 平安〜江戸中期の数字はほとんど残っていないため、研究の目安で埋めて「推計」の印を出す（作る人の了承）
  - 生まれる旧国：鬼頭宏の旧国別の推定人口（900・1150・1600年）と、1721年からの幕府の調査（Wikipedia「近代以前の日本の人口統計」「江戸時代の日本の人口統計」）
  - 寿命：人骨の研究（鎌倉の由比ヶ浜南遺跡 24.0年、吉母浜遺跡 20.6年）をもとに、1000年 28年、1200年 24年、1450年 21.5年、1650年 28年、1800年 35.8年（男）とつないだ
  - 豊かさ：Maddison Project の1000・1150・1280・1450・1600・1700年の値。1600年より前のお金は貫文（米1石がおよそ1貫文の目安）
  - 元号：Wikipedia「元号一覧 (日本)」。南北朝の時代（1336〜1392年）は北朝の元号
- 中世の身分（貴族・武士・百姓・職人や商人・僧・下人・河原者や非人）も抽選し、差別は事実に沿って控えめに書く（作る人の判断）。貴族は山城国だけ
- 北海道は擦文文化（1199年まで）とアイヌ（1200年から）、沖縄はグスク時代（1428年まで）と琉球王国（1429年から）の呼び方で出す（作る人の判断）。1600年より前の北海道と1608年までの沖縄には、本州の年表と全国の飢饉を出さない
- 年表 1000〜1799年 116行、時代のようす 39行、場面 69、亡くなる出来事 32件（刀伊の入寇・源平・養和や寛喜の飢饉・元寇・明応地震・応仁の乱・戦国の戦・島原・天草一揆・明暦の大火・宝永地震・天明の飢饉など）、名前（平安・中世・公家）、ドット絵（烏帽子・垂髪・直衣・袿・直垂）
- 1700年より前の子どもは寺子屋がまだ少ないため、字を習うのは寺での手習い（貴族は家学）として少なめにした

## きょうだいとして生きる・継がない子の道・一生の浮き沈み（作る人の指示書 2026年10月17日）

- 名前を「1000分の1」にそろえ、作る人が作り直したトップ（千年の盤・生まれた人と亡くなった人の数）を取り込んだ。原作の表記は許可を得た形のまま
- きょうだいとして生きる：最期の画面で同じ家のきょうだい（生きている人と、これから生まれる弟や妹）を選ぶと、その人として前の人が亡くなった年から続きを生きる。両親・祖父母・きょうだいの生死は前の人生の記録どおり（亡くなった年までは抽選し直さない）、本人も亡くなった年までは亡くならない。家の引っ越し（1975年以降の生まれ）も同じ年に同じ町へ。記録は1人目の種ときょうだいの番号だけを持つ（v2）。トップの「これまでの人生」は家ごとに1行
- 跡取り：生きている男子のうちいちばん年上の子。男子がいなければいちばん年上の娘が婿を迎える。1898〜1947年は明治民法、1897年以前は目安（推計の印）、1948年からは決めない
- 継がない子の道（1600〜1947年）：奉公（百姓・町人・明治からの平民の子。家の豊かさの3つの層と男女で割合を変える。速水融『歴史人口学の世界』の西条村の目安）、年季明けに村へ戻るか町に残るか、町人の男子の手代・番頭・まれなのれん分け、分家（地主の層だけ。1673年の分地制限令。武士はまれ。明治からは都市に出た次男・三男が結婚を機に）、婿養子（跡取りの男子がいない家の割合を、子どもの数と亡くなる割合から計算）、武士の次男・三男の養子（徳島藩の研究の割合を目安に）。婿養子・養子に入った人は新しい名字と旧姓を出す。家の名字は日本に多い名字から選ぶ（江戸時代の百姓・町人は公には名乗れなかったため、家の呼び名として扱う）
- 戦後の形（1948年から）：長男が父の死後に墓を守る・年老いた母と同居する出来事。妻の名字を選ぶ結婚は、人口動態統計の夫妻の氏別婚姻件数（2015〜2024年。2014年以前は2015年の値）
- 最期の画面：一生の浮き沈み（暮らしの満足の曲線、いちばん良かった年・つらかった年・大きく下がった年・結婚・最初の子の印、同じ町・同じ年の100人の平均の線、時代の区切り）、その時代のお金での生涯の稼ぎ（例「約160両と約4,728円」）。地図・人生地図・生き残り・100人・時代の出来事は「ほかの記録を開く」の中
- 指示書と合わないところ：武士の当主のうち養子の割合は、1701〜1750年はおよそ29%（表34.0%）、1751〜1800年はおよそ32%（表47.6%）。今の人生の作りでは生き残る次男・三男の数が足りず、表の値まで上がらない（検査Mで不合格として出る）
