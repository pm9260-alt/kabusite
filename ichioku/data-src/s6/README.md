# 第6版の選択と場面（JSON）の書き方

ファイル：`choices-<名前>.json`（選択）と `lines-<名前>.json`（場面の一文）。どちらも JSON 配列。
確かめ方：`node tools/build-s6.mjs --only choices-<名前>.json`（エラーが0件になるまで直す）

## 選択（choices-*.json）
```
{
  "id": "s6.kurai.ashigaru.1",          // 半角小文字・数字・点。ほかと重ならない
  "kind": "small",                      // small（本人の選択）/ parent（0〜5歳の子の親としての選択）
  "y": [1603, 1867], "a": [18, 60],     // 出せる年（西暦）と年齢
  "when": { "grade": ["ashigaru"] },    // 条件（下の表）
  "text": ["問いの文1", "書き分けた問いの文2"],   // 1つ以上。同じ中身の書き分けを入れてよい（1つの人生で同じ文は1回だけ出る）
  "options": [
    { "k": "naishoku", "l": "傘張りの内職を増やす", "fx": { "sat": -1, "body": -1, "tie": 1 }, "money": { "f": 0.05 },
      "after": "夜ごとに傘の骨に紙を張り、薬代の足しにした。" },
    { "k": "kotowaru", "l": "内職を断り剣の稽古に通う", "fx": { "learn": 2, "body": 1, "sat": -1 }, "money": { "f": -0.03 },
      "after": "内職の口は隣の長屋の者に回り、稽古場で汗を流した。" }
  ],
  "src": ["key"]                         // 出典（あれば。data-src/paths/sources*.json の鍵）
}
```
- 答えは2〜3つ。どの答えにも、得るもの（fx のどれかが＋、または money.f が＋）と失うもの（fx のどれかが−、または money.f が−）を両方入れる
- fx は sat（暮らしの満足）・learn（学び）・tie（つながり）・body（からだ）。−5〜+5 くらい
- after は選んだあとに記録に出る1文。相手・品物・場所のどれかを入れて具体的に。普通体・過去形で「。」で終える
- text の問いの文は普通体（「〜た。」「どうする？」は書かなくてよい）。40〜90字くらい

## 場面の一文（lines-*.json）
```
{ "id": "s6.l.kurai.ashigaru.1", "y": [1603, 1867], "a": [16, 70], "when": { "grade": ["ashigaru"] },
  "t": ["長屋の井戸端で、組頭の噂話を聞いた。", "書き分け"], "cat": "学歴と仕事" }
```
- cat は 家庭・地域・時代・健康・人間関係・学歴と仕事 のどれか
- t は普通体・過去形で「。」で終える。20〜60字

## when（条件）の鍵
| 鍵 | 例 | 意味 |
|---|---|---|
| kind | ["village","fish","town","city"] | 今住む土地の種類（村・浜の村・町・市街地） |
| ind | ["farm","fish","shop","craft","office","bushi","priest"] | 仕事の種類 |
| status | ["hyakusho","chonin","bushi","kuge","priest","heimin","shizoku","modern"] | 身分（1975年からの生まれは modern） |
| sex | "m" / "f" | 性別 |
| unmarried / married / divorced / childless / hasChild / hasSib / parentOld / poor / rich | true | 未婚・既婚・離縁したことがある・子がいない・子がいる・きょうだいがいる・70歳以上の親がいる・暮らしが苦しい・暮らし向きが上 |
| pref | ["40"] | 今住む都道府県の番号（2けた） |
| kakaku | ["sekke"] | 貴族の格（data-src/paths/README.md の表） |
| grade | ["ashigaru"] | 武士・軍人の位（同じ表） |
| jobIs | ["遣明船の水夫"] | 今の仕事の名前 |
| rank | ["shogun","daimyo"] | 将軍家・大名家 |
| crime | true | 罪を犯したことがある |

## 差し込み
{name} 本人 / {dad} 父 / {mom} 母 / {spouse} 配偶者 / {child} 子 / {friend} 友 / {place} 生まれた土地 / {sibOlder} 兄姉 / {sibYounger} 弟妹 / {en} 縁談の相手（「とら（21歳・隣村の本百姓の家の次女）」の形）/ {enName} 縁談の相手の名前 / {job} 今の仕事の名前
差し込みの人がいないときは、その選択や場面は出ない。

## 守ること（指示書 spec6 の決まり）
- 地名・役職・品物・言葉はその時代の呼び方にする。品物は出せる年の範囲を守る（スマートフォン2008年〜、家庭の携帯電話1995年〜、貸本屋は1970年まで、テレビ1953年〜、電子レンジ1965年〜、パソコン1980年〜、インターネット1995年〜、鉄砲1543年〜、たばこ1590年〜、さつまいも1605年〜など）
- 1946年からは「祝言」と書かず「結婚式」。市街地（city）に「村」を出さない
- 実在の人は背景にだけ出す。帝は「帝」「主上」と書き、名前を出さない
- 使わない言葉：まず／見ます／効く／効いて／重い・重く・重さ・重かった／読み（「読み書き」「読み方」も不可）／判定／一方で／結論から言うと／示唆／わけです／極めて／興味深い／齟齬／——。半角のかっこ () は使わない（全角の（　）はよい）
- 実在の会社名は出さない
- つらい出来事は事実を短く書き、むごい描写を重ねない。罪のやり方の細かい手順は書かない
