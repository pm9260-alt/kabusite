# 人生の筋（パス）の書き方（JSON）

ファイルは JSON 配列。1つの要素が1つの筋。

```
{
  "id": "botanist1",                 // 半角英数字。ほかの筋と重ならない名前（ファイルごとに接頭辞を付ける。例 b_ / c_ / e_）
  "title": "草木の名前",              // 分かれ道の見出し（短く）
  "y": [1700, 1867],                  // その筋が始まる年の範囲（西暦）
  "a": [8, 14],                       // 始まる年齢の範囲
  "st": ["hyakusho", "chonin"],       // 生まれの身分（どれか）。省略はどの身分でも。今の時代（1975年からの生まれ）は "modern"
  "sex": "m",                         // 省略は男女とも
  "kind": ["village", "fish"],        // 土地の種類（village 村・fish 浜の村・town 町・city 都会）。省略はどこでも
  "p": 0.02,                          // 条件に合う1年ごとに始まる確率（0.005〜0.04 くらい）
  "text": "{name}は、畑のわきに生える草の名前を一つ残らず覚えたがった。…どうする？",   // 問いの文。差し込み {name} {dad} {mom} {place}（なくてもよい）
  "opts": [ 選択肢, 選択肢 ]          // 2〜3つ
  "nodes": { "名前": 場面, ... }      // あとで起きる場面
}
```

選択肢（opts と、場面の ask の中）:
```
{ "k": "go", "l": "本草学の先生に弟子入りを頼む", "f": ["study"], "w": 1,
  "say": "選んだあとに記録に出る1文（普通体・過去形・「。」で終える）",
  "fx": { "sat": 3, "learn": 5, "tie": -2, "body": 0 },   // 4つの数値の動き（-10〜+10）
  "job": { "n": "本草学者の弟子", "pay": 900, "cat": "craft" },   // 仕事が変わるとき（省略可）。pay はその時代の年収のめやす（両・円などの数字。昔は 500〜5000、今は 2000〜9000 の万円単位ではなく千円単位でよい）。cat は farm/fish/shop/craft/office/samurai/temple/teacher/clerk/service のどれか
  "status": "bushi",                  // 身分が変わるとき（取り立てられて武士に、など。省略可）。使える値：bushi kuge priest chonin hyakusho heimin shizoku
  "move": "edo",                      // 住む所が変わるとき（edo / kyoto / osaka / tokyo / home）。省略可。home は生まれた土地に戻る
  "away": true,                       // 家を出て暮らすとき true（家族の場面が便りの形になる）。家に戻るときは move:"home"
  "next": { "in": [3, 6], "node": "teacher" }   // 何年後にどの場面へ進むか（省略可）
}
```
f は「今年の重点」に合う答え：study 学ぶ・earn 稼ぐ・family 家族・body からだ・save 貯める。

場面（nodes の値）:
```
{ "say": "記録に出る1文", "fx": {...}, "job": {...}, "status": "...", "move": "...", "away": true,
  "ask": { "title": "見出し", "text": "問いの文", "opts": [選択肢...] },   // 場面の中で、また分かれ道を出すとき（say のあとに出る）
  "next": { "in": [2, 5], "node": "次の場面" } }
```

守ること
- **誘導しない**：どの分かれ道でも「地元に残る」「家を継ぐ」などの答えを必ず入れ、その答えにも、何年かあとに地元で幸せに暮らす場面（next でつなぐ）を用意する。偉くなる答えだけが得をする書き方にしない（fx も釣り合わせる）。
- 時代に合わない言葉・品物を出さない（江戸以前に「学校」「会社」「円」など）。実在の会社名・実在の人物の名前は出さない（「ある大名」「幕府の役所」のように書く）。歴史上の制度・出来事は本当にあったものだけ。
- 文は普通体・過去形（〜た。）。人生の記録の1行として読める長さ（20〜60字）。必ず「。」で終える。答えの文（l）は短く（4〜18字）。
- 使わない言葉：まず／見ます／効く／効いて／重い・重く・重さ／読み（「読み書き」「読み方」も不可）／判定／一方で／結論から言うと／示唆／わけです／極めて／興味深い／齟齬／——。半角のかっこ () は使わない。
- 差し込みは {name} {dad} {mom} {place} だけ。
- 1つの筋は、始まり→2〜4つの場面くらい。分かれ道（ask）は筋の中で2つまで。

## 第6版で足した項目（指示書 spec6。2026-10-21）

筋の項目（どれも省略できる）
```
"group": "kaigai",          // 筋の種類：kaigai 海を渡る・遠くを旅する（2-2）/ shusse 中央で働く出世（2-3）/ botsuraku 貴族の没落（2-5）/
                            //   gun 軍で成り上がる（2-8）/ kurai 武士・士族・軍人の位ごと（2-9）/ jiken 歴史の出来事に沿った物語（2-13・2-17）/
                            //   shoku 仕事ごとの物語（2-19・2-23）/ ijou 偉業（2-26）/ gaiseki 外戚争いと政略結婚（2-28）/ tsumi 罪（2-30）/
                            //   kakaku 貴族の格ごと（2-1）/ senkyo 選挙（2-11）
"pref": ["40", "41"],       // 今住んでいる土地の都道府県の番号（2けたの文字。01北海道〜47沖縄）。旧国は今の県に読みかえる
"kakaku": ["sekke"],        // 貴族の格（下の表）。書いた格の家の人だけ
"grade": ["ashigaru"],      // 武士・軍人の位（下の表）。その位の人だけ
"jobIs": ["遣明船の水夫"],  // 今の仕事の名前（jobs.json の名前）がこのどれかの人だけ
"rank": ["shogun"],         // 将軍家 shogun・大名家 daimyo の人だけ（今までどおり）
"once": true,               // true なら、条件に合った最初の年に1回だけ p で引く（p は「その人生で出会う割合」。出来事の物語は 0.3〜0.5）
"src": ["kimiya1955"],      // 出典の番号（data-src/paths/sources.json の鍵）。新しい筋には必ず付ける
"married": false            // false なら未婚の人だけ（今までどおり）
```

選択肢・場面の項目（どれも省略できる）
```
"die": { "n": "船の遭難", "t": "海で嵐にあい、船とともに沈んだ。" },  // その年に亡くなる。n は死因の呼び名（記録と死因の一覧に出る）、t は最期の文
"abroad": "宋",             // 海の外へ渡る（記録に移った先として残る）。帰るときは "move": "home"
"honor": { "t": "従五位下", "k": "ikai" },  // 位階 ikai・勲章 kunsho・褒章 hosho・褒美 hobi・死後の贈位 zoui
"crime": { "t": "盗み", "pun": "遠島" },     // 罪と罰（記録に残る。あとで縁談や仕事の場面に出る）
"free": true,               // 刑を終えた
"money": { "f": -0.3 },     // 貯金を増やす・減らす（f は貯金に対する割合。-0.3 は3割減る）
"debt": 200,                // 借金を足す（その時代のお金の単位の数。負の数は返す）
"kakakuSet": "urin",        // 家の格を変える（養子・取り立てなど）
"gradeSet": "kachi",        // 位を変える（上がる・下がる）
"feat": true,               // この結末は、出世や外れ値・偉業の「いちばん上の結末」（Japapedia の対象）
"quit": true                // 筋で就いた仕事を辞める（家の仕事に戻ってよい）
```

差し込みに {en} を足す：縁談・告白・恋の相手を「とら（21歳・隣村の本百姓の家の次女）」の形で出す（相手は筋ごとに1人に決まる）。
{enName} は相手の名前だけ。

出典（data-src/paths/sources.json）
```
{ "kimiya1955": { "name": "木宮泰彦『日華文化交流史』冨山房、1955年", "note": "入宋僧・入元僧の記録" } }
```
本や資料の名前は、実在が確かなものだけを書く。人数や割合などの数字は、出典にあるものだけを使う。

決まり（第6版）
- 地名・役職・品物・言葉はその時代の呼び方にする（宋・元・明・唐土・天竺・南蛮・博多の唐房・寧波など）。今の言い方を添えるときは全角の（　）で
- 実在の人は背景にだけ出す（「栄西という僧が宋から茶の種を持ち帰ったと聞いた」）。主人公と家族は架空の人
- 帝（天皇）は「帝」「主上」、皇子は「東宮」「皇子」と書き、名前を出さない
- うまくいく道だけにしない（遭難・異国で死ぬ・失脚・家族と疎遠）。地元に残る答えには、地元で幸せに暮らす続きを必ず用意する
- どの答えにも「その答えだけが得られるもの」と「失うもの」を1つずつ以上持たせる（fx の4つの数のうち、1つ以上を＋、1つ以上を−にする。money・debt も失うものに数える）
- つらい出来事（人さらい・身売り・飢饉・公害・戦）は事実を短く書き、むごい描写を重ねない。罪のやり方の細かい手順は書かない
- 1つの筋の中で、選ばなかった答えの続きは出ない（作りが自動で消す）
