# 人生の筋（パス）の書き方（JSON）

ファイルは JSON 配列。1つの要素が1つの筋。

```
{
  "id": "botanist1",                 // 半角英数字。ほかの筋と重ならない名前（ファイルごとに接頭辞を付ける。例 b_ / c_ / e_）
  "title": "草木の名前",              // 分かれ道の見出し（短く）
  "y": [1700, 1867],                  // その筋が始まる年の範囲（西暦）
  "a": [8, 14],                       // 始まる年齢の範囲
  "st": ["hyakusho", "chonin"],       // 生まれの身分（どれか）。省略はどの身分でも。今の時代（1975年からの生まれ）は "modern"
  "sex": "m",                         // 省略は男女とも
  "kind": ["village", "fish"],        // 土地の種類（village 村・fish 浜の村・town 町・city 都会）。省略はどこでも
  "p": 0.02,                          // 条件に合う1年ごとに始まる確率（0.005〜0.04 くらい）
  "text": "{name}は、畑のわきに生える草の名前を一つ残らず覚えたがった。…どうする？",   // 問いの文。差し込み {name} {dad} {mom} {place}（なくてもよい）
  "opts": [ 選択肢, 選択肢 ]          // 2〜3つ
  "nodes": { "名前": 場面, ... }      // あとで起きる場面
}
```

選択肢（opts と、場面の ask の中）:
```
{ "k": "go", "l": "本草学の先生に弟子入りを頼む", "f": ["study"], "w": 1,
  "say": "選んだあとに記録に出る1文（普通体・過去形・「。」で終える）",
  "fx": { "sat": 3, "learn": 5, "tie": -2, "body": 0 },   // 4つの数値の動き（-10〜+10）
  "job": { "n": "本草学者の弟子", "pay": 900, "cat": "craft" },   // 仕事が変わるとき（省略可）。pay はその時代の年収のめやす（両・円などの数字。昔は 500〜5000、今は 2000〜9000 の万円単位ではなく千円単位でよい）。cat は farm/fish/shop/craft/office/samurai/temple/teacher/clerk/service のどれか
  "status": "bushi",                  // 身分が変わるとき（取り立てられて武士に、など。省略可）。使える値：bushi kuge priest chonin hyakusho heimin shizoku
  "move": "edo",                      // 住む所が変わるとき（edo / kyoto / osaka / tokyo / home）。省略可。home は生まれた土地に戻る
  "away": true,                       // 家を出て暮らすとき true（家族の場面が便りの形になる）。家に戻るときは move:"home"
  "next": { "in": [3, 6], "node": "teacher" }   // 何年後にどの場面へ進むか（省略可）
}
```
f は「今年の重点」に合う答え：study 学ぶ・earn 稼ぐ・family 家族・body からだ・save 貯める。

場面（nodes の値）:
```
{ "say": "記録に出る1文", "fx": {...}, "job": {...}, "status": "...", "move": "...", "away": true,
  "ask": { "title": "見出し", "text": "問いの文", "opts": [選択肢...] },   // 場面の中で、また分かれ道を出すとき（say のあとに出る）
  "next": { "in": [2, 5], "node": "次の場面" } }
```

守ること
- **誘導しない**：どの分かれ道でも「地元に残る」「家を継ぐ」などの答えを必ず入れ、その答えにも、何年かあとに地元で幸せに暮らす場面（next でつなぐ）を用意する。偉くなる答えだけが得をする書き方にしない（fx も釣り合わせる）。
- 時代に合わない言葉・品物を出さない（江戸以前に「学校」「会社」「円」など）。実在の会社名・実在の人物の名前は出さない（「ある大名」「幕府の役所」のように書く）。歴史上の制度・出来事は本当にあったものだけ。
- 文は普通体・過去形（〜た。）。人生の記録の1行として読める長さ（20〜60字）。必ず「。」で終える。答えの文（l）は短く（4〜18字）。
- 使わない言葉：まず／見ます／効く／効いて／重い・重く・重さ／読み（「読み書き」「読み方」も不可）／判定／一方で／結論から言うと／示唆／わけです／極めて／興味深い／齟齬／——。半角のかっこ () は使わない。
- 差し込みは {name} {dad} {mom} {place} だけ。
- 1つの筋は、始まり→2〜4つの場面くらい。分かれ道（ask）は筋の中で2つまで。
